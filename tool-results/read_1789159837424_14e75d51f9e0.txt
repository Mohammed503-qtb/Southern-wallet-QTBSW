   831→
   832→| الطبقة | التقنية | ملاحظات |

   845→**قيود معمارية إلزامية:**
   846→
   847→1. الواجهة لا تتعامل مع قاعدة البيانات مباشرة: UI → UseCase → Repository → API.

   903→
   904→| الكيان | الحالات |
   905→|---|---|
   906→| الحساب | `PENDING → ACTIVE ⇄ RESTRICTED ⇄ FROZEN → SUSPENDED → CLOSED` |

   908→| المعاملة | `CREATED → VALIDATING → AUTHORIZED → PROCESSING → COMPLETED` (+ `FAILED / REJECTED / CANCELLED / EXPIRED / REVERSED / UNDER_REVIEW`) |
   909→| السحب | `CREATED → PENDING → AUTHORIZED → READY_FOR_COLLECTION → COLLECTED → COMPLETED` (+ رفض/انتهاء/إلغاء/عكس) |
   910→| الحوالة | `CREATED → PENDING_DELIVERY → DELIVERED → COMPLETED` (+ `EXPIRED / CANCELLED / REVERSED`) |
   911→| الأهلية | `ELIGIBLE / PENDING_REVIEW / RESTRICTED / OUTSIDE_SERVICE_AREA / BLOCKED` |
   912→| الخدمة | `ON / OFF / MAINTENANCE` |
   913→| النظام | `ACTIVE / MAINTENANCE / READ_ONLY / SERVICE_DEGRADED / BLOCKED` |
   914→| الوكيل | `ACTIVE / SUSPENDED / BLOCKED` |
